# 笔记问答与登录交互调整需求

1. 登录页使用白色背景。
2. 点击“新会话”不立即写入数据库，只有会话产生消息后才创建并保存。
3. 去掉会话初始化 loading 对用户输入和页面的阻塞。
4. 无真实思考内容时，等待状态只显示两行：思考中、当前任务进展状态。
5. 有真实思考内容时，以打字机效果展示思考过程。
6. 会话初始化滚动直接定位，不触发平滑滚动动画；新消息滚动可继续使用动画。
7. 去掉合集前端功能，包括导航、路由、问答侧栏筛选和前端 API/状态代码；后端接口和数据库保留兼容性。
8. 检查并修复用户反馈的 403 问题，确保 CSRF 令牌缺失或过期时客户端能够刷新并重试一次，避免重复提交。
9. 统一浏览器 favicon 与页面品牌图标，只保留一种 favicon 资源。
